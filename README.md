# MUA Insurance Rwanda — Frontend

Phase 2 homepage redesign concept for MUA Insurance Rwanda.

## Stack

- Next.js (App Router) + TypeScript
- CSS Modules + design tokens from Phase 1
- No UI kit / animation libraries

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scope

- Homepage only (hero through footer)
- Content sourced from Phase 0 inventory / live `mua.rw`
- Internal product/company routes are linked but not implemented yet

## Brand

- Logo: official MUA SVG (`public/brand/mua-logo.svg`)
- Colors: `#0033A1` / `#FF671D`
- Display font fallback: Manrope (Isidora pending license)
- Body: Nunito Sans
