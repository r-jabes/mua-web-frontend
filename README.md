# MUA Insurance Rwanda — Frontend

Public website frontend for MUA Insurance Rwanda.

## Stack

- Next.js (App Router) + TypeScript
- CSS Modules + design tokens
- No UI kit / animation libraries

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Brand

- Logo: official MUA SVG (`public/brand/mua-logo.svg`)
- Favicon: `public/brand/mua-icon.svg`
- Colors: `#0033A1` / `#FF671D`
- Display font: Manrope
- Body: Nunito Sans
